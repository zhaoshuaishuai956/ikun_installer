# 爱坤工具箱业务插件图标语义表

版本：v1.0 · 日期：2026-08-31 · 状态：设计输入

> 本文件只回答“一个功能应该用什么视觉语义表达”，不定义颜色、投影、位图格式或菜单注册规则。
> 工程规则以《NX二次开发权威规范》为准；在册插件集合仍只以根目录 `plugins.json` 为事实源。
> 下列条目由 `plugins.json` 派生，`ci/check_consistency.py` 会检查每个在册插件恰好有一条语义记录，
> 因而本文件不能自行新增或删除插件。

## 1. 证据与方法

语义依据按以下优先级交叉确认：

1. `plugins.json` 确定在册集合和打包分支；
2. 各仓 `plugin.meta` 确定四字中文名和类别；
3. 对应分支的 DLX 控件、业务入口和建模/导出函数确定用户实际操作与结果；
4. 菜单 `LABEL` 仅用于核对名称，不反推功能；README、历史报告和注释不作为授权。

每枚图标使用同一语义句式：

> 对【主对象】执行【主动作】，得到【关键结果】；依靠【区别特征】与相邻命令区分。

图标信息优先级固定为：**主对象 > 主动作 > 必要结果**。状态、品牌色和装饰不进入业务语义。
一个 32px 图标原则上只保留一个主体和一个动作修饰；无法在无文字、无颜色时成立的方案，应退回重做。

## 2. 插件语义表

<!-- plugin-semantic:MultiEntityNester -->
### 2.1 `MultiEntityNester` — 实体排样

| 字段 | 定义 |
|---|---|
| 功能句 | 对多个已存在实体执行二维紧凑排样，得到满足间距和方向约束的低占地布局。 |
| 主对象 | 多个轮廓不同的实体，而不是规则相同的字符块。 |
| 主动作 | 在平面边界内移动、可选旋转并相互嵌合。 |
| 关键结果 | 多个不规则轮廓被紧凑容纳，外包络面积明显减小。 |
| 区别特征 | “不规则实体 + 紧凑外包络”；区别于活字排版的等规格字块，也区别于普通矩形阵列。 |
| 图标主体 | 3 个大小或轮廓不同的简化实体，彼此错位嵌合在一个边界内。 |
| 动作修饰 | 由紧凑边界或一组很短的位移箭头表达；优先保留紧凑关系。 |
| 小尺寸保留 | 至少能看出“多个不同形状”和“压紧后的外边界”。 |
| 禁用隐喻 | 单独九宫格、单个齿轮、相同方块阵列、文字或字母缩写。 |

<!-- plugin-semantic:block_boss_layout -->
### 2.2 `block_boss_layout` — 定位凸台

| 字段 | 定义 |
|---|---|
| 功能句 | 在活动块贴合区域自动或手动布置带孔定位凸台，并在配合体生成相应凹槽。 |
| 主对象 | 贴合面上的带中心孔圆柱凸台。 |
| 主动作 | 定位布点并建立凸台/凹槽配合关系。 |
| 关键结果 | 一侧形成凸台，另一侧形成与之对应的容纳凹槽，同时避让加热管。 |
| 区别特征 | “短粗定位凸台 + 配合凹槽”；区别于细长顶针和普通孔创建。 |
| 图标主体 | 两个相接板面中的一个短圆柱凸台，清楚显示中心孔或对应凹位。 |
| 动作修饰 | 小型定位十字或对合关系；不同时叠加螺栓、加号和多根箭头。 |
| 小尺寸保留 | 凸台必须明显高于板面，中心孔与外圆不能粘连。 |
| 禁用隐喻 | 单独螺栓、单独圆孔、顶出箭头、泛化的设置齿轮。 |

<!-- plugin-semantic:ejector_layout -->
### 2.3 `ejector_layout` — 顶针布局

| 字段 | 定义 |
|---|---|
| 功能句 | 在模具和顶针板条件下布置多个顶针位置，得到避让加热管并满足壁厚的顶出方案。 |
| 主对象 | 多根细长顶针及其在板面上的圆形位置。 |
| 主动作 | 阵列或手动布点，并沿脱模方向顶出。 |
| 关键结果 | 顶针位置形成可制造的分布，必要时同时建立顶针板。 |
| 区别特征 | “多个细针 + 共同顶出方向”；区别于单个短粗定位凸台。 |
| 图标主体 | 板面上的 3–4 个顶针圆位，其中一根可露出短柱身。 |
| 动作修饰 | 一支统一方向的顶出箭头；避免给每根顶针都画箭头。 |
| 小尺寸保留 | 多点分布和顶出方向必须同时可读。 |
| 禁用隐喻 | 单根螺栓、普通孔阵列、定位十字、与定位凸台相同的单柱构图。 |

<!-- plugin-semantic:pmi_hole_dim -->
### 2.4 `pmi_hole_dim` — 孔位标注

| 字段 | 定义 |
|---|---|
| 功能句 | 识别选定平面上的孔并创建 PMI 位置尺寸，得到可读的横纵坐标和必要外形尺寸。 |
| 主对象 | 平面上的孔中心及外轮廓基准。 |
| 主动作 | 测量并标注，不创建或加工孔。 |
| 关键结果 | 孔中心与基准边之间出现标准尺寸线、界线和箭头。 |
| 区别特征 | “孔 + 尺寸线”；区别于打孔、孔表和几何测量。 |
| 图标主体 | 一个或两个清晰孔环，配一组横向/纵向尺寸线。 |
| 动作修饰 | 尺寸箭头和界线本身就是动作，不再叠加铅笔或加号。 |
| 小尺寸保留 | 孔环、尺寸线和箭头必须保持分离，数值文字可以完全省略。 |
| 禁用隐喻 | 只有尺子、只有孔、表格、不可读的尺寸数字。 |

<!-- plugin-semantic:single_line_text -->
### 2.5 `single_line_text` — 单线刻字

| 字段 | 定义 |
|---|---|
| 功能句 | 将用户文字转换为单线曲线并放置到指定坐标系，得到适合刻写的线或样条。 |
| 主对象 | 无封闭填充的单线字形笔画。 |
| 主动作 | 沿基线排字并生成曲线。 |
| 关键结果 | 输出只有中心线几何，不产生实体厚度。 |
| 区别特征 | “开放单线字形”；区别于有面积、有厚度的拉伸文字。 |
| 图标主体 | 一个可辨认但不过度细化的开放单线字形，放在短基线上。 |
| 动作修饰 | 基线或曲线路径即可，不额外增加挤出箭头。 |
| 小尺寸保留 | 笔画必须明确是单线，不能因双描边看成实体文字。 |
| 禁用隐喻 | 填充粗体字母、三维挤出侧面、段落文本、刻刀照片化图形。 |

<!-- plugin-semantic:text_auto_layout -->
### 2.6 `text_auto_layout` — 文字排版

| 字段 | 定义 |
|---|---|
| 功能句 | 将多行文字按字符间距和行距排布并拉伸，得到带厚度和可选拔模的实体文字。 |
| 主对象 | 一行或多行具有实体宽度的文字轮廓。 |
| 主动作 | 按行排布并沿法向拉伸。 |
| 关键结果 | 形成连续的多行三维文字，而不是单线曲线或独立活字底板。 |
| 区别特征 | “多行文本 + 挤出厚度”；区别于单线刻字和活字排版。 |
| 图标主体 | 两行简化文字轮廓或文本条，其中前排显示少量侧面厚度。 |
| 动作修饰 | 一支短法向拉伸箭头或可见侧面，二选一。 |
| 小尺寸保留 | 至少保留两行关系和实体厚度；不要求字符内容可读。 |
| 禁用隐喻 | 单独字母 A、独立小方块网格、排样外框、段落编辑光标。 |

<!-- plugin-semantic:plate_dwg_export -->
### 2.7 `plate_dwg_export` — 板面导出

| 字段 | 定义 |
|---|---|
| 功能句 | 从每个实体选择一个平面，提取其内外轮廓并导出为分层 DWG。 |
| 主对象 | 带外环和内孔的平面板轮廓。 |
| 主动作 | 从 NX 模型向外导出二维轮廓。 |
| 关键结果 | 获得方向正确、内外环可分层的 DWG 文件。 |
| 区别特征 | “板面轮廓 + 外向导出”；区别于保存零件、截图和创建板实体。 |
| 图标主体 | 正视板轮廓，至少保留一个内孔以说明导出的是轮廓集合。 |
| 动作修饰 | 使用全套统一的外向导出箭头；箭头不遮挡主轮廓。 |
| 小尺寸保留 | 外轮廓、内孔和箭头三者必须分离。 |
| 禁用隐喻 | 以 `DWG` 字样为主体、文件夹、软盘、三维复杂板件截图。 |

<!-- plugin-semantic:type_layout -->
### 2.8 `type_layout` — 活字排版

| 字段 | 定义 |
|---|---|
| 功能句 | 按批次规则或自定义清单计算各字符数量，生成带底板的活字并紧凑排成可制造字盘。 |
| 主对象 | 多个带字符凸起的独立活字底板。 |
| 主动作 | 计算数量、复制活字并按最小间距进行近方形排版。 |
| 关键结果 | 得到每块均可独立加工和取用的活字集合，可选附加线切割边框或整料。 |
| 区别特征 | “等规格独立字块 + 字符差异 + 紧凑字盘”；区别于连续实体文字和不规则实体排样。 |
| 图标主体 | 4–6 个等规格小字块组成紧凑矩阵，少数块保留简化字符笔画。 |
| 动作修饰 | 矩阵外形本身表达排版；空间允许时再用一条短间距线，不叠加导出符号。 |
| 小尺寸保留 | 必须看出每个字符有独立底板，不能合并成一整块文本面。 |
| 禁用隐喻 | 单独一个字母、普通文本段落、不规则实体嵌套、把线切割/DWG当作主语义。 |

## 3. 跨插件统一词汇

| 视觉词汇 | 固定含义 | 使用范围 |
|---|---|---|
| 外向箭头 | 导出到外部文件 | 当前只用于板面导出；其他插件即使含可选导出，也不抢占主语义。 |
| 尺寸线与箭头 | 创建尺寸或标注 | 孔位标注；不能表示移动。 |
| 单向顶出箭头 | 沿脱模方向运动 | 顶针布局；不能复用于普通导出。 |
| 定位十字 | 定位或配合中心 | 定位凸台；不能代替一般选择点。 |
| 紧凑外包络 | 排样结果 | 实体排样；活字排版优先使用规则字块矩阵区分。 |
| 可见挤出侧面 | 形成三维实体厚度 | 文字排版；单线刻字禁止使用。 |

## 4. 对抗性审查清单

### P0 阻断

- 图标离开颜色后无法辨认，或与另一个插件拥有相同主轮廓；
- 使用警告、错误、成功等系统状态符号表达普通业务功能；
- 图标语义与 `plugin.meta.name_cn`、菜单 `LABEL` 或实际业务结果不一致；
- 为追求统一而修改既有 `BUTTON`、`ACTIONS` 或插件身份。

### P1 修复后通过

- 32px 下包含超过一个主体和一个动作修饰；
- 使用不可读缩写、尺寸数字或完整 CAD 截图；
- 可选附属功能压过主功能，例如让活字排版图标主要表现 DWG 导出；
- 只在大图成立，缩小后孔环、间隙、底板或单线结构粘连。

### P2 记录改进

- 需要在 NX 1847 Ribbon 的实际大/中/小按钮和高 DPI 下继续做相邻辨识测试；
- 当前语义表不决定颜色与投影，视觉方案变化时不得反向改变这些功能语义；
- 插件业务能力变化后，应先更新实现与 `plugin.meta`，再同步本表并通过一致性检查。
