# 子项目开发规范（执行摘要）

> 唯一权威源：`docs/NX二次开发权威规范.md`。本文件只供子项目执行时速查；发生冲突时以权威规范为准。

## 强制规则

1. 创建前先问用户是否并入爱坤工具箱。
2. 新项目英文身份四同：仓库名、目录名、工程/DLL 基名、插件 id 完全相同；小写 snake_case，≤28 字符。
3. `plugin.meta.name_cn` 必须是**正好四个汉字**且反映主要功能；菜单/Ribbon LABEL 与其逐字相同。
4. 必须导出 `ufusr`、`ufusr_ask_unload`，后者返回 `UF_UNLOAD_IMMEDIATELY`。
5. 所有并入工具箱的业务插件必须复制统一 `ikun_update_check.hpp`，并在 `ufusr` 的
   `UF_initialize()` 前调用 `IkunUpdateReminder::CheckOnceOnFirstPluginUse()`。
6. 首次更新触发的语义是：每个 NX 进程第一次点击任意业务插件时启动一次
   `ikun_installer.exe --check-update`；只由安装器判断版本和提示。用户关闭提示后，本会话不得再次强提醒。
7. 已有插件通过同目录原子覆盖 DLL/DLX 热更新，关闭插件窗口后再次点击原 bar 按钮即可使用，无需重启；
   只有新增插件因菜单尚未注册需要重启 NX。覆盖失败必须保留旧文件并提示重试。
8. 源码、DLL/DLX/DAT、CHANGELOG 同一提交；构建脚本不得硬编码私有路径，secret 不得入库。

## 并入清单

- [ ] `plugin.meta`：四字 `name_cn`、合法 `icon_cn/category`、`in_ikun=true`
- [ ] `plugins.json` 登记 repo/ref
- [ ] startup 菜单与 Ribbon：LABEL、ACTIONS、BITMAP 一致，GBK 无损
- [ ] `notify-installer.yml` 从安装器模板复制
- [ ] `ikun_update_check.hpp` 已复制且 `ufusr` 已调用
- [ ] `ufusr_ask_unload == UF_UNLOAD_IMMEDIATELY`
- [ ] CHANGELOG、双导出、DLX XML、CI、一键构建与 NX 1847 冒烟通过
- [ ] 验证已有插件热更新、新插件重启边界和首次点击仅检查一次
