# 01 · 环境与要求

> 动手前先确认本章每一项。**预检清单**在文末——逐条打勾再写代码。
>
> 适用于 NX 二次开发**全模块**：建模 / CAM / 装配 / 制图 / PMI / 钣金 …。三个必链库 + dll 骨架 + 编译加载对所有模块一致，模块差异只在**追加的库**和 `run()` 里调用的 API 命名空间（见 §3 与 [`04`](04-控件与读值速查.md)）。
>
> **零基础一键准备**：不想手动装的，直接跑 [`templates/setup-nx-dev-env.ps1`](templates/setup-nx-dev-env.ps1)——它按本章清单自动检测、用 winget 装齐 Git / Python / **VS 的 C++ 工具集** / Windows SDK，最后**真编译一个样例 dll 来验证环境就绪**。NX SDK 是付费软件装不了，只检测并提示。

## 1. 软件环境

| 项 | 值 |
|---|---|
| **NX 版本** | 1847 |
| **SDK 根** | NX 安装目录下的 `UGOPEN`（默认 `C:\Program Files\Siemens\NX 1847\UGOPEN`；可由 `UGII_ROOT_DIR` 的父目录推出） |
| **头文件** | `uf*.h`、`NXOpen\*.hxx`（都在 SDK 根下） |
| **库文件** | `*.lib`（同在 SDK 根下） |
| **编译器** | VS2022（需勾「使用 C++ 的桌面开发」工作负载） |
| **官方示例** | `…\UGOPEN\SampleNXOpenApplications\C++\BlockStyler\` |

## 2. 工程目录约定

- 工程根目录下**每个插件一个子目录**（`<工程根>/<工程名>/`）。
- **dll + dlx 同目录部署**（dll 在运行时从自身目录拼 dlx 绝对路径，见 [`03-踩坑总账.md`](03-踩坑总账.md) §流程协作）。
- 工程名用英文，作文件名 / 类名前缀 / dll 名。

## 3. 三个必链库（缺一即一堆 LNK2019）

| 库 | 提供 |
|---|---|
| `libufun.lib` | UF_* C 函数 |
| `libnxopencpp.lib` | Session / UI / NXMessageBox |
| `libnxopenuicpp.lib` | **Block Styler 全家桶 + UI::CreateDialog（最易漏）** |

**按模块追加库**（头文件在 `UGOPEN\NXOpen\<模块>\*.hxx`）：
- `libugopenint.lib` —— UF_UI 选择 / specify
- `libnxopencpp_features.lib` —— 建模特征
- `libnxopencpp_geometricutilities.lib` —— 几何工具（Xform/CSYS 等）
- `libnxopencpp_cam.lib` —— **CAM**（工序 / 刀路 / 后处理，命名空间 `NXOpen::CAM`）
- `libnxopencpp_annotations.lib` —— **PMI / 制图标注**（`NXOpen::Annotations`）
- `libnxopencpp_assemblies.lib` —— **装配**（`NXOpen::Assemblies`）
- `libnxopencpp_drafting.lib` —— **制图**（`NXOpen::Drafting`）

> 症状导向：链接报 `LNK2019 无法解析的外部符号` 且符号名含某模块类名 → 多半漏了该模块对应的 `libnxopencpp_<模块>.lib`。缺 `libnxopenuicpp.lib` 最常见（Block Styler + CreateDialog）。

## 4. 关键编译开关

```
/MD /EHsc /utf-8 /D_CRT_SECURE_NO_WARNINGS
```

- **`/utf-8` 必加**：源码是 UTF-8 无 BOM，不加则 cl 按 GBK(936) 读中文注释 → 满屏 C2059 语法错。
- `C4275`（std::exception 作 NXException 基类）是 NXOpen 头自带，无害忽略。
- `vswhere.exe` 报 "not recognized" 无害，cl 仍能跑。
- **环境导入与编译必须同一次调用**：`cmd /c "call vcvars64.bat && cl ..."`（PowerShell 工具的环境变量不跨调用）。
- **不要写 LF 换行的 .bat 去 cd 中文目录再调 cl**（cmd 按 GBK 解 UTF-8 路径会乱码）。一律走 [`templates/build.ps1`](templates/build.ps1)。

## 5. 加载方式

NX 打开 .prt → **Ctrl+U** → 选 dll。`ufusr_ask_unload` 返 `UF_UNLOAD_IMMEDIATELY`，改完重编可直接再 Ctrl+U，**无需重启 NX**。
