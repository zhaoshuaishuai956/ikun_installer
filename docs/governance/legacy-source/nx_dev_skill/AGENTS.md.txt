# AGENTS.md — 给接手 NX 二次开发的 AI 会话（私有仓）

本仓库 `nx_dev_skill`（私有）是 Siemens **NX 1847** 二次开发的单一可信知识库 **+ 维护要求**。你若要在本工作区做 NX/UG 插件，**先读再动手**。

> 公开镜像仓 `nx_dev_handbook` 与本仓共享同一套知识，但**不含**维护协议本身（本文「你的义务」一节）与 `scripts/`、`CONTRIBUTING.md`。新坑登记进**本私有仓**，确认后脚本会把同一条坑一并同步到公开仓。

## 上手顺序

0. **全程遵守 [`05-执行协议.md`](05-执行协议.md)**：需求确认卡未经用户确认不写代码；只拷模板最小改写；编译前自查；报错查 [`06-报错决策表.md`](06-报错决策表.md)（同一报错限修 2 次）；拿不准照 [`07-完整范例.md`](07-完整范例.md)。
1. 读 [`03-踩坑总账.md`](03-踩坑总账.md) 全部分类标题 + [`01-环境与要求.md`](01-环境与要求.md) 预检清单。
2. 按 [`02-标准流程.md`](02-标准流程.md) 走：厘清需求 → 拷 [`templates/`](templates/) 改写 → `build.ps1` 编译 → `dumpbin` 验证 → NX 里 Ctrl+U 加载。
3. 写控件 / 读值 / 建模时翻 [`04-控件与读值速查.md`](04-控件与读值速查.md)。

## 你的义务（同步协议）

解决了一个新的共性坑，**生成一条登记建议交用户确认**——这是知识库存活的方式。**你（agent）不要自动提交**：跑下面这条命令（不带 `-Commit`）只会弹出建议、不改任何文件：

```powershell
pwsh -File scripts/add-pitfall.ps1 -Category <9类之一：中文编码|控件读值|保留字|链接库|API|几何算法|流程协作|CAM|模块专属> -Phenomenon "现象" -Cause "根因" -Fix "解法"
```

把它打印的建议原样转述给用户。**用户确认后**，才在同一条命令末尾加 `-Commit` 执行写入+提交+推送（私有仓 + 公开仓 `nx_dev_handbook`）——由用户运行，或用户明确同意后你再运行。

细则见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。只想留私有加 `-NoMirror`。若工作区另存了一份本地速查文档，确认后顺手补同一行保持一致。

## 环境/目录/仓库出问题？先跑 doctor

```powershell
pwsh -File scripts/doctor.ps1
```

一键体检 + 自愈：自动发现/克隆公开仓、认领 remote、自签证书、非快进 rebase、离线只本地提交不丢数据；修不了的给确切命令。详见 [`CONTRIBUTING.md`](CONTRIBUTING.md)「出任何问题先跑 doctor」。
