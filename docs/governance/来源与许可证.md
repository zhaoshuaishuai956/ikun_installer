# 归并来源与许可证

2026-08-25 将原有 NX 二次开发知识、整体规范和公开手册归并进 `ikun_installer`，目的为消除多级权威与镜像漂移。

- 技术知识和较新模板来自原私有知识库，现位于 `docs/nx-development/`。
- 整体规范、登记快照和历史对抗审查来自原规范库，现位于 `docs/governance/`。
- 公开手册与私有知识库重叠；经逐文件比较，采用较新的私有版本，保留公开来源的许可证文本。
- 三份来源许可证原文位于 `docs/governance/source-licenses/`。
- `旧版整体规范-v1.0-已废止.md` 与 `registry-历史快照.json` 只用于历史审计，不具现行规则或登记效力。

现行唯一权威源是 `docs/NX二次开发权威规范.md`；在册插件唯一集合源是根目录 `plugins.json`。
