# 爱坤工具箱 — NX 模具设计插件集

面向 Siemens NX 1847 的模具设计插件集合：**8 个插件**覆盖排样、凸台、顶针、孔位标注、刻字与排版，由安装器统一部署，支持 NX 内自动更新。

## 安装

1. 从本仓库 **Releases → latest** 下载 `ikun_installer.exe`，运行安装。
2. 打开 NX：主菜单栏末尾出现 **爱坤工具箱** 菜单，工具栏显示对应图标。
3. 更新：每个 NX 会话首次点击任一插件时自动检查更新，有新版即在后台原子替换，**下次点击即用新版**；新增插件需重启 NX 以载入菜单。也可通过菜单中的「检查更新」手动触发。

## 使用方法

> 通用步骤：打开 NX 部件 → 主菜单 **爱坤工具箱 → 对应菜单项** → 在对话框中操作 → **确定** / **应用**。

### 实体排样（MultiEntityNester）

把多个实体投影成 2D，在板材范围内自动排样。

1. 打开含实体的模型，点击「实体排样」。
2. 选择各实体底面：可切换「智能识别冒口」（框选任意面自动识别最大支承底面）；手动模式下每个实体只能选一个平面，重复面与非平面自动剔除。
3. 已选列表支持单击高亮，并可分别设置每个实体参与排版的数量。
4. 设置板材尺寸、间距、旋转角度；「高级」分组可选四档算法（BL 基线 / Compact-BLF / Adaptive Best-Fit / Beam-LNS）与可复现随机种子。
5. 开始排样 → 可开启四算法 SVG 预览对比布局与利用率，点击卡片后由 NX 实际落位。

▶ [操作演示视频](docs/videos/MultiEntityNester.mp4)

### 定位凸台（block_boss_layout）

在模具活动块上自动创建安装定位凸台，与实体布尔求和。

1. 打开模具模型（建模环境），点击「定位凸台」。
2. 设置凸台参数（直径、高度、边距等）→ 选择放置面与参考边 → 确定。
3. 支持多选面批量生成。

### 顶针布局（ejector_layout）

快速布置顶针并自动做干涉 / 超界检查。

1. 点击「顶针布局」→ 选择放置面、加热管柱面（可多选）、顶针板范围面。
2. 设直径 / 长度 / 安全间隙 → 指定落点，点「添加该点」逐个加入位置表（加入时即时报该点状态）。
3. 点「检查全部」：加热管干涉（壁间隙小于安全间隙 → `[干涉]`）、顶针板超界（落在面外 → `[超界]`），结果输出到信息窗口。
4. 确定 / 应用：只对 `[OK]` 的落点生成顶针。

### 孔位标注（pmi_hole_dim）

选一个规则矩形平面，自动识别面上圆孔并生成 PMI 标注。

1. 点击「孔位标注」→ 选择平面（限单面）。
2. 每个孔生成两个 PMI 垂直距离尺寸：水平（面左边 → 孔心）、竖直（面下边 → 孔心）；面厚度放最左。
3. 「标注方式」下拉有两种样式：
   - **原样式**：尺寸按阶梯排布 + 孔编号引线；
   - **孔表**：表格列为 序号 / X / Y / 孔径，单元格关联测量表达式——移动孔、改孔径或修改板件后更新模型即联动刷新。
4. 默认「仅标注通孔」，关闭后可包含盲孔。

> 提示：孔表坐标以所选面在当前工作视图中的左下角为原点。

### 单线刻字（single_line_text）

把中文 / 英文 / 数字转成 CAM 可用的单线字体曲线，用于刻字加工。

1. 点击「单线刻字」。
2. 填写文字（可多行）→ 设字高 / 字宽 / 比例 → 选择坐标系（整字块中心落在原点）→ 应用。
3. 支持字符最小间距与字形尺寸联动。

### 文字排版（text_auto_layout）

输入文字自动生成曲线并拉伸（可拔模）成实体，居中、等间距关联排版。

1. 点击「文字排版」。
2. 输入文字内容（每行一排）→ 选放置坐标系（原点=放置点，X=排字方向）→ 选字体（需 TrueType，默认黑体）。
3. 设字高 / 拉伸厚度 / 拔模角 / 字符间距 / 行距 → 应用。
4. 每个字符逐个生成并关联，分字 100% 准确；对话框打开时以青色临时线实时预览轮廓（不创建特征）。

▶ [操作演示视频](docs/videos/text_auto_layout.mp4)

### 活字排版（type_layout）

按批次号规则生成活字底板与立体文字（日期章 / 批号章），自动统计用量与排版。

1. 点击「活字排版」→ **先选放置坐标系**（必选，排版方向与叠加方向均取自该坐标系）。
2. 选批次规则（四位年+月符号+日 / 六位全数字 / 四位年+月月+日字母）、规格预设（5x7 / 6x8）、型腔数量、年份范围；也可自定义 字符,数量 清单。
3. 设置底板尺寸 X/Y/Z、文字厚度 T、字体高度 H、拔模斜度、活字最小间距等。
4. 附加材料可选「整体包容」或「线切割」（自动创建边框实体）；可启用缺口补位填满网格。
5. 确定生成 → 对话框实时显示每种活字数量、总数与预计网格；勾选「生成线切割 CAD」可在创建前调出保存对话框导出 DWG（未检测到 AutoCAD 时交付俯视 DXF）。

▶ [操作演示视频](docs/videos/type_layout.mp4)

### 板面导出（plate_dwg_export）

把多个实体上的平面轮廓按排样布局导出为 DWG，供线切割 / 激光切割使用。

1. 点击「板面导出」→ 选择要导出的平面（每个实体只能选一个，非平面选中即实时剔除）。
2. 设置输出目录与文件名（默认部件目录 + 同名 `.dwg`）、排样间距、排样行宽。
3. 可勾选：内外环分图层、导出后打开文件夹、导出后用默认软件打开。
4. 确定（导出并关闭）或 应用（导出并保留对话框）。

▶ [操作演示视频](docs/videos/plate_dwg_export.mp4)
